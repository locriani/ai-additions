# CEILINGS.md — §11, once a limiting claim is in hand

**Purpose**: The frame carries §11's rule and its recognizer. This file carries what is
needed only after a candidate sentence exists — the catalogue of sentences that are never
invariants, and the four arguments that get one written anyway.

## Never invariants, in any repo

- "This has **no / 0 / 1** dependencies, and that is a good thing"
- "GitHub doesn't matter here"
- "This only has to work with the current user's exact directory layout"
- a **`Runtime dependencies:` ledger** in a doc — `pyproject.toml` / `package.json` already
  holds the set; the prose copy exists only to be defended, and goes stale the first time
  the real one changes

## Rationalizations

```
descriptive(intent)     ⊬ descriptive(read)     you meant "is"; it reads "must stay"
minimal(now)            ⊬ virtue(minimal)       a count is a measurement, not a goal
◇¬need(X)               ⊬ □¬need(X)             ◇P ⊬ P, and the arrow runs both ways
scoped(this_PR)         ⊬ scoped(the_project)   the PR ends; the sentence does not
```

Every row is one slip: a true present-tense observation written where it reads as a rule.
The fix is not to soften it — record the *reason* the code has its shape, which stays true,
instead of the *limit*, which does not.
